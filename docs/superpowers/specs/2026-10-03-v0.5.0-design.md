# 뽁이 v0.5.0 — "커맨드 팔레트" 설계서

- 작성일: 2026-10-03
- 상태: 브레인스토밍 승인 완료 → 구현 계획 대기
- 테마: **클립보드 히스토리 + 스니펫 + 통합 검색 팔레트**
- 포지셔닝: *뽁이 = 나만의 커맨드 팔레트*

## 1. 범위

### v0.5.0 포함
- **클립보드 히스토리** — 복사한 텍스트 최근 N개 자동 저장
- **스니펫** — 핀 고정한 메모가 곧 스니펫 (별도 저장소 없음)
- **통합 팔레트** — `Ctrl+Alt+M` 소환 · 메모·스니펫·클립보드·바로가기 통합 검색
- **보안 기본선** — 민감 패턴 자동 제외 + 캡처 일시정지 토글
- **bubble 간소화** — 포모도로 버튼 제거 (유저 미사용 피드백)
- **설정 섹션 추가** — 클립보드 보관 수량 · 캡처 enabled 토글

### 제외 (YAGNI, v0.6+ 보류)
- 이미지 클립 (텍스트 only)
- 앱 포커스 기반 비번 매니저 자동 제외
- 클립 formatted text (HTML/RTF)
- 캐릭터 알림/리마인더
- 캐릭터 스킨 교체
- 포모도로 완전 제거 (코드 유지, bubble 버튼만 뺌)

### 성능 목표
- 클립보드 폴링 500ms, idle CPU 영향 미미 (<0.5%)
- 상시 메모리 v0.4.1 수준 유지 (~520 MB)
- 팔레트 소환부터 결과 렌더까지 <100ms (100개 소스 기준)

## 2. 아키텍처 개요

```
Main process
├── ClipboardWatcher (new) — 500ms 폴링, 민감 패턴 필터, Store 저장
├── Store (기존) — clipboard.json 추가
├── Palette window (new, lazy) — Ctrl+Alt+M 소환
├── ipcMain
│    palette:search(query) → { memos, snippets, clipboards, launchers }
│    palette:select(item) → copy or launch
│    palette:deleteClip(id) · palette:clearClipHistory()
│    clipboard:togglePaused() → boolean
├── Tray (modified) — "📋 클립보드 캡처 일시정지" 토글 추가
└── 기존 shortcuts.ts: Ctrl+Alt+M 핸들러를 팔레트 소환으로 교체

Palette renderer (new)
├── 입력창 + 결과 리스트 (fuzzy or substring match)
├── 결과 타입별 아이콘 (📝 📎 📋 🚀)
├── Enter: 복사 or 실행 · Shift+Enter: 편집 창 열기 (메모/스니펫)
└── Esc 또는 blur: 창 닫기

Bubble renderer (modified)
└── ⏱ 포모도로 버튼 1개만 삭제 (나머지 유지)
```

### 핵심 원칙
- **클립보드 상태는 main에만** — 폴링·필터·저장 전부 main. renderer는 IPC로만 접근.
- **스니펫 = 핀 메모** — 메모 Store 재사용. `pinned: true`를 "스니펫 역할"로 간주.
- **팔레트는 lazy** — Ctrl+Alt+M 눌릴 때 생성, 닫히면 destroy (v0.4.0 window-registry 패턴 재사용).

## 3. 데이터 모델

### 3.1 Clipboard entry

새 Store: `%APPDATA%\BOKKI\clipboard.json`

```ts
export type ClipboardEntry = {
  id: string;              // uuid
  text: string;            // 복사된 텍스트 (최대 10,000자, 초과 시 저장 skip)
  copiedAt: string;        // ISO
};
```

- 리스트는 `copiedAt desc`로 정렬. 최대 수량(기본 50) 넘으면 오래된 것부터 drop.
- **중복 처리**: 바로 직전 entry와 text가 같으면 skip (연속 동일 복사 무시). 과거 entry와 같으면 과거 entry를 리스트 맨 앞으로 이동 (중복 생성 X).
- `pinned` 필드 **없음** — 스니펫은 별도.

### 3.2 Snippet = Pinned Memo

메모 Store(`memos.json`) 그대로 사용. 기존 `pinned: boolean` 필드가 "스니펫 여부" 역할.

- 메모 UI는 기존대로 (전체 리스트 · 핀 상단 고정)
- 팔레트는 "메모 전체"와 "스니펫(핀만)" 둘 다 검색 소스로 사용
- 유저 멘탈 모델: "자주 쓰는 거 핀 꽂아두면 자동으로 스니펫"

### 3.3 Settings 확장

```ts
// src/shared/types.ts
export type Settings = {
  // 기존 필드...
  clipboardCaptureEnabled: boolean;   // 기본 true
  clipboardMaxEntries: number;        // 20~200, 기본 50
};
```

## 4. 팔레트 UX

### 4.1 소환
- 전역 단축키: `Ctrl+Alt+M` (기존 "빠른 메모" 교체)
- 소환 시 팔레트 창 중앙(또는 커서 근처) show + focus + 입력창 autofocus
- blur 시 즉시 hide (`setPointerCapture`로 drag 중일 땐 유지)

### 4.2 레이아웃

```
┌────────────────────────────────────────┐
│ 🔍 _____________________________  (ESC) │
├────────────────────────────────────────┤
│ 📝 메모    회의록 템플릿                   │
│ 📎 스니펫  제 이메일: ccg0611@...          │
│ 📋 클립보드 (방금) https://github.com/...  │
│ 📋 클립보드 (3분전) const foo = bar       │
│ 🚀 바로가기 VS Code                      │
└────────────────────────────────────────┘
     ↑↓ 이동 · Enter 복사·실행 · Shift+Enter 편집
```

### 4.3 검색
- 빈 쿼리일 때: **최근 사용 순 상위 20개** (최근 클립 우선 + 자주 쓰는 스니펫)
- 쿼리 입력: 각 소스에서 `text.includes(query)` (대소문자 무시). fuzzy는 v0.6.
- 결과 상한: 각 타입 10개씩 (총 40개 cap, 스크롤 가능)

### 4.4 액션

| 타입 | Enter | Shift+Enter |
|---|---|---|
| 메모 | 클립보드에 복사 | 메모 창에서 편집 모드 |
| 스니펫(핀 메모) | 클립보드에 복사 | 메모 창에서 편집 |
| 클립보드 | 다시 클립보드에 복사 | — |
| 바로가기 | 실행 | — |

Enter 후: 토스트 "복사됨!" or "실행됨" + 팔레트 자동 close.

### 4.5 "빠른 메모" 유지

기존 유저가 `Ctrl+Alt+M = 메모 작성 창` 멘탈 모델을 가짐. 팔레트에 **인라인 명령어** 지원:

- 입력창에 빈 상태로 Shift+Enter → "새 메모 작성" 창 열기
- 또는 입력 후 Ctrl+Enter → **입력 텍스트를 새 메모로 저장**

문서/온보딩에서 "메모를 바로 쓰려면 열자마자 Shift+Enter" 1줄 안내.

## 5. 클립보드 캡처 + 보안

### 5.1 캡처 메커니즘

```ts
// src/main/clipboard-watcher.ts (신규)
import { clipboard } from "electron";

let lastText = "";
let paused = false;

const interval = setInterval(() => {
  if (paused || !settings.clipboardCaptureEnabled) return;
  const text = clipboard.readText();
  if (!text || text === lastText) return;
  if (isSensitive(text)) { lastText = text; return; }
  lastText = text;
  store.addEntry(text);
}, 500);
```

- 500ms 폴링. 네이티브 이벤트 사용 X (Electron 복잡도 대비 이득 작음).
- `lastText` 캐시로 중복 즉시 reject.

### 5.2 민감 패턴 자동 제외

`isSensitive(text)` heuristic:

```ts
// 아래 중 하나라도 매치 → skip
- /^\d{13,19}$/                                   // 카드번호 (공백/하이픈 제거 후)
- /^\d{6}$/                                       // 6자리 숫자 (2FA 코드)
- /^[A-Z0-9+/=]{40,}$/                            // base64 토큰
- /^(?=.*[A-Z])(?=.*[a-z])(?=.*\d)(?=.*[\W_]).{10,}$/  // 비밀번호 heuristic
                                                   // (대문자+소문자+숫자+특수문자 10자 이상)
```

**철학**: 완벽 분류 X, false negative(민감한데 저장됨) 허용. 다만 가장 위험한 비번·카드·2FA 패턴은 잡는다. 유저가 민감한 작업 중일 땐 "일시정지" 사용.

### 5.3 캡처 일시정지

- 트레이에 "📋 클립보드 캡처 일시정지" 체크 메뉴 → 체크 시 `paused = true`
- 설정 창의 "클립보드 캡처 활성화" 토글과 동기화
- 토글 즉시 적용 (앱 재시작 불필요)

### 5.4 10,000자 상한

- 클립보드 text > 10,000자 → 저장 skip. 로그 X. (대용량 복사는 보통 코드 블록, 저장 가치 낮음)

## 7. 테스트 전략

### 유닛 (Vitest)
- `ClipboardWatcher`: 중복 skip · 재정렬 · max entries · pause · 민감 패턴 각 case
- `isSensitive`: 카드·2FA·토큰·비밀번호 패턴 × 양성/음성 각 3개
- Store 확장: `clipboard.json` CRUD

### E2E (Playwright Electron)
- 팔레트 소환 → 입력 → 메모 선택 → 클립보드 값 확인
- 클립보드에 복사 → 500ms 대기 → 팔레트에서 히스토리 보임
- 캡처 일시정지 토글 → 복사해도 저장 안 됨

### 수동 체크리스트 (release 전)
- 비밀번호 매니저 복사 → 저장 안 됨
- 2FA 6자리 복사 → 저장 안 됨
- `Ctrl+Alt+M` 소환 → 100ms 이내 뜸
- 트레이 "일시정지" 체크 → 즉시 반영
- bubble에서 ⏱ 사라졌는지 확인

## 8. 마이그레이션 / 호환성

- `settings.json`: 신규 필드 2개는 `DEFAULT_SETTINGS`에서 기본값. 기존 유저는 로드 시 merge.
- `clipboard.json`: 신규 파일. 없으면 빈 배열로 초기화.
- `memos.json`: 변경 없음.
- 기존 `Ctrl+Alt+M = 빠른 메모` 유저는 Shift+Enter 또는 Ctrl+Enter 안내 필요 → 설정 창 "도움말" 섹션에 한 줄 추가.
